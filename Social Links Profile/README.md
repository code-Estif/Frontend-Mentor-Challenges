### What I learned

In this project, I focused on achieving pixel-perfect accuracy based on the design provided. I practiced:
- Implementing a robust CSS reset for consistent cross-browser behavior.
- Using CSS variables to manage colors and typography centrally.
- Refining spacing (padding/margins) to create a clean, balanced layout.
- Designing interactive hover states with smooth transitions.

```css
.social-link {
  transition: all 0.3s ease;
}

.social-link:hover {
  background-color: var(--clr-green);
  color: var(--clr-grey-900);
}
```
