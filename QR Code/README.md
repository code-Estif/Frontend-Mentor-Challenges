# QR Code Component

A clean and responsive QR code component built as a challenge for [Frontend Mentor](https://www.frontendmentor.io). This project focuses on fundamental CSS skills like layout centering, typography, and card styling.

## 🚀 The Challenge

The objective was to build a QR code component that matches the provided design as closely as possible.

### Key Features
- **Responsive Layout**: Adapts to different screen sizes.
- **Modern Typography**: Uses the 'Outfit' font family.
- **Center-Aligned UI**: Perfectly centered using Flexbox.

## 🛠️ Built With

- **HTML5**: Semantic markup for structure.
- **CSS3**: Custom properties (variables) and Flexbox layout.
- **Google Fonts**: [Outfit](https://fonts.google.com/specimen/Outfit) font implementation.

## 💡 What I Learned

This project was a great refresher on:
- Using `min-height: 100vh` and Flexbox to center a card both vertically and horizontally.
- Implementing custom CSS variables for a consistent color palette.
- Managing image responsiveness within a fixed-width container.

```css
/* Centering the card */
body {
    display: flex;
    justify-content: center;
    align-items: center;
    min-height: 100vh;
}
```
